# Security and deployment boundary

This is a local starter, not a production service, compliance certification or authorization system. Use synthetic data until recording consent, provider processing, access, retention/deletion and release policies are approved. A private GitHub repository does not make downstream model processing private.

- The HTTP server binds only 127.0.0.1. All supported routes including health require a bearer token (minimum 24 characters), supplied via ROCKNOTE_TOKEN. No CORS, URL fetching, arbitrary file paths, send/publish routes, dynamic plugins or HTTP release operation. Maximum request body 1 MiB; socket timeout 10 seconds. Logs omit requests/headers. Single-threaded stdlib server is only a development bridge, not hardened against hostile traffic.
- Never port-forward it publicly. Remote access requires a separately implemented and reviewed production service with TLS, identity validation, meeting-scoped authorization, request/rate limits, audit logging without content/secrets, secret management, encrypted storage, retention/deletion, monitoring and network isolation. Local bearer auth is NOT Entra authentication. Tenant deployment/Teams/Graph ingestion are not implemented.
- All canonical fields, quotes and model output are untrusted. HTML escapes text; CSV prefixes formula-like cells; unknown schemas/keys and duplicate JSON keys are rejected. Semantic entailment, consent, completeness and corporate authority cannot be established deterministically.
- CLI release requires named reviewer, approval timestamp and both approval flags. Those are local operator attestations, not cryptographic approvals or RBAC. Model/REST tools only produce previews and cannot release. Production must enforce an independent human approval channel; never accept review flags from model output as sufficient identity evidence.
- Output editions include original canonical-input bytes and evidence. These folders are restricted, not public artifact bundles. Recap HTML omits full transcript but includes cited quote excerpts; review sensitive content before any authorized distribution. Hashes are tamper-evidence, not confidentiality. Preserve original platform export separately under approved controls; ingest preserves only supplied JSON bytes.
- Do not store credentials, patient/personnel data, real meeting transcripts or private exports in Git. .gitignore is not a security scanner. Token names are safe to document; values are not.

Report vulnerabilities privately to the repository owner using an approved private channel. Do not open public issues containing evidence or credentials. No external outreach is configured by this kit.
